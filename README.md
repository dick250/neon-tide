Neon Tide — an original open-world crime game that runs entirely in the browser. Play as Lucia "Luz" Vega, a getaway driver in the neon coastal city of Coral Bay, working off a debt across a chain of story missions. Drive or walk a 10×10-block city with traffic, pedestrians, stealable cars, a five-star wanted system with police chases, roadblocks, a helicopter and SWAT, five weapons, gun shops, spray shops, taxi fares, a day-night cycle, synthesized music and sound, and local saves. Built with three.js and hand-written physics; every model, texture and sound is procedural and original — no third-party assets, no network calls at runtime.

## Run it

```sh
node serve.ts
```

Then open the URL it prints (desktop Chrome, keyboard + mouse). `node main.ts` rebuilds the submission dossier into `out/`.
